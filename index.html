Email Accounts
Connect multiple email accounts — send, receive, and track replies inside the CRM
0 connected
Receiving replies: Email replies land in your actual inbox. To pull them into the CRM, use the ↻ Check Replies button in the Email section — it will import any Brevo inbound emails. For automatic syncing, set up Brevo's inbound parsing to forward replies to your webhook.
Inbound Email Webhook (Brevo)
To receive replies automatically: In Brevo → Settings → Inbound Parsing → add this webhook URL:
https://oipkvwdjlwienkphsivr.supabase.co/functions/v1/email-inbound

Google Calendar
Create and sync events directly into Google Calendar for you and your clients
Not connected
Setup (one time):
1. Go to console.cloud.google.com
2. New Project → Enable Google Calendar API
3. Credentials → Create OAuth 2.0 Client ID → Web application
4. Add Authorized JavaScript origin: https://qhva-crm.vercel.app
5. Paste your Client ID below and click Authorize with Google
Google Calendar connected
To create events and invite clients, go to the Calendar section and click + New Event. All events sync directly to your Google Calendar.
